# AI-Powered IT Support & Asset Management System

A web-based IT support and asset management system developed using Python Flask and SQLite. The system helps manage employee IT support tickets, track IT assets, and provide AI-assisted troubleshooting suggestions for common technical issues.

## Features

- Employee and Admin demo login
- IT support ticket creation and management
- Ticket priority and status tracking
- IT asset management
- Asset assignment tracking
- Dashboard for tickets and assets
- AI-assisted troubleshooting for common IT issues
- SQLite database for persistent data storage
- REST API implementation using Flask
- Simple and user-friendly web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- REST API
- VS Code
- Git & GitHub
